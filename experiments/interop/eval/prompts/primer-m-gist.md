1. Components are Flutter's Material widgets 1:1: same names, the constructor's parameters as props, `child` / `children` as JSX children, other widget parameters as JSX-valued props, named constructors concatenated (`Image.network` is `<ImageNetwork src>`).
2. Dart values are plain data: enums and static constants are strings ("spaceBetween", "Curves.easeInOut"), classes are objects keyed by constructor parameter name, with `$` selecting a named constructor or a subclass (`{ $: "symmetric", horizontal: 8 }`, `{ $: "BoxDecoration", color: "white" }`); no method calls on values.
3. Colors also take names or CSS hex strings, EdgeInsets/BorderRadius a number, Duration milliseconds; icons are imported by name (`import { star } from "solid-fuse/icons/material"`, `<Icon icon={star}>`); callbacks get Flutter's details objects as plain data.
