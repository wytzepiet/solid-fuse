Runtime semantics of this API (read from the Dart implementation; treat as ground truth):
- `<View>` builds, inside to outside: children (see flex below) -> Padding(padding) -> Align(alignment) -> clip (if clipBehavior set: ClipRRect using decoration.borderRadius when present, otherwise ClipRect; `shape: "circle"` does NOT make the clip circular) -> DecoratedBox(decoration) (so the background covers the padding; a shadow is painted outside and is not clipped by the same View's clip) -> AspectRatio -> SizedBox(width, height) -> ConstrainedBox(min/max) -> Opacity -> Transform(rotate, scale, translate) -> Padding(margin) -> IgnorePointer -> Visibility -> Flexible(flex: grow).
- `grow={n}` wraps the View in `Flexible(fit: FlexFit.loose)` unless `fit="tight"` is given. So `grow={1}` alone does NOT force the child to fill the remaining space: the child may be smaller, and siblings after it are not pushed to the far edge. (The documentation describes grow as "takes remaining space"; the runtime default is loose. When a criterion fails ONLY because of this, mark it "fail" and add the tag "grow-loose" to that criterion.)
- Children layout: a single child with no flex options is returned as is. Otherwise a Flutter `Flex`: direction vertical unless "horizontal"; mainAxisSize is max when `expand: true` or when `justify` is anything other than "start", else min; crossAxisAlignment from `align` (default start); `gap` is spacing. Several children without a `flex` prop become a vertical Flex (min).
- `<ScrollView>` is a SingleChildScrollView around the same children layout (axis from scrollDirection or flex.direction). `<Stack>`/`<Positioned>` are Flutter's. `<GestureDetector>` is Flutter's (default behavior deferToChild: empty space without a painted/hit-testable child is not tappable).
- `<Text>` with non-TextSpan element children lays them out inline (WidgetSpan) and wraps them like words.
- `<Image>`: fit defaults to cover; `borderRadius` clips with ClipRRect.
- There is no animation support: a prop change applies instantly unless the component drives intermediate values itself with timers.
- Color strings that are not one of the 16 names or a #hex are ignored (no color).
- Otherwise ordinary Flutter layout rules apply (unbounded constraints, Flexible only inside a flex parent, Positioned only inside Stack, a vertical Flex with max main size inside a vertical scroll view throws, etc.).
