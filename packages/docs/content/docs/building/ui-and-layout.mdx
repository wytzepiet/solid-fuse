Every built-in widget ships as an uppercase wrapper component imported from `solid-fuse`. They take typed props and render to native Flutter widgets.

## View

`View` is the workhorse layout container. It maps to a composition of Flutter widgets — Container, Padding, SizedBox, Opacity, Transform, and more — depending on which props you set.

```tsx
import { Text, View } from "solid-fuse";

<View
  padding={16}
  decoration={{ color: "#FFFFFF", borderRadius: 12, boxShadow: [{ blurRadius: 8, color: "#0002" }] }}
>
  <Text fontSize={18}>Card content</Text>
</View>
```

### View props

| Prop | Type | Description |
|---|---|---|
| `layout` | `LayoutInput` | How the children lay out (see [Layout](#layout) below) |
| `padding` | `EdgeInsetsGeometry` | Inner spacing |
| `margin` | `EdgeInsetsGeometry` | Outer spacing |
| `width` / `height` | `number` | Fixed dimensions |
| `minWidth` / `maxWidth` | `number` | Size constraints |
| `minHeight` / `maxHeight` | `number` | Size constraints |
| `aspectRatio` | `number` | Width-to-height ratio |
| `alignment` | `AlignmentGeometry` | Align child within view |
| `decoration` | `BoxDecoration` | Background, borders, shadows, gradients |
| `foregroundDecoration` | `BoxDecoration` | Decoration painted on top |
| `opacity` | `number` | 0–1 transparency |
| `transform` | `TransformInput` | Rotate, scale, translate |
| `clipBehavior` | `string` | Clip behavior (`"hardEdge"`, `"antiAlias"`, `"none"`) |
| `flex` | `number` | Share of the parent layout's free space (see [flex](#flex)) |
| `testId` | `string` | Finds the element in tests and tools; on every element (see [Developing with agents](/docs/building/agents#find-elements)) |
| `visible` | `boolean` | Show/hide without removing from tree |
| `ignorePointer` | `boolean` | Disable hit testing |

## Text

`Text` renders Flutter `Text` widgets.

```tsx
import { Text } from "solid-fuse";

<Text fontSize={24} fontWeight={700} color="#2563EB">
  Hello world
</Text>
```

### Text props

| Prop | Type | Description |
|---|---|---|
| `fontSize` | `number` | Font size in logical pixels |
| `fontWeight` | `FontWeight` | `100`–`900`, as in CSS |
| `fontFamily` | `string` | Font family name |
| `fontStyle` | `string` | `"normal"` or `"italic"` |
| `color` | `Color` | Text color |
| `lineHeight` | `number` | Line height multiplier |
| `letterSpacing` | `number` | Space between characters |
| `textAlign` | `string` | `"left"`, `"right"`, `"center"`, `"justify"`, `"start"`, `"end"` |
| `maxLines` | `number` | Maximum number of lines |
| `overflow` | `string` | `"clip"`, `"fade"`, `"ellipsis"`, `"visible"` |
| `textDecoration` | `TextDecoration` | `"underline"`, `"overline"`, `"lineThrough"`, `"none"` |
| `backgroundColor` | `Color` | Highlight behind text |
| `shadows` | `Shadow[]` | Text shadows, e.g. `[{ blurRadius: 4, offset: [0, 2], color: "#0004" }]` |

## Stack and Positioned

`Stack` layers children on top of each other. `Positioned` places children at specific coordinates within the stack.

```tsx
import { Positioned, Stack, Text, View } from "solid-fuse";

<Stack alignment="center">
  <View width={200} height={200} decoration={{ color: "#2563EB" }} />
  <Positioned top={10} right={10}>
    <Text color="#FFFFFF">Badge</Text>
  </Positioned>
</Stack>
```

| Stack prop | Type | Description |
|---|---|---|
| `alignment` | `AlignmentGeometry` | Default alignment for children |
| `fit` | `string` | `"loose"`, `"expand"`, `"passthrough"` |
| `clipBehavior` | `string` | Clip overflowing children |

| Positioned prop | Type | Description |
|---|---|---|
| `top` / `left` / `right` / `bottom` | `number` | Offset from stack edges |
| `width` / `height` | `number` | Fixed dimensions |

## ScrollView

`ScrollView` creates a scrollable container.

```tsx
import { ScrollView, Text, View } from "solid-fuse";

<ScrollView padding={16} physics="bouncing">
  <View layout={{ gap: 8 }}>
    <For each={items()}>{(item) => <Text>{item}</Text>}</For>
  </View>
</ScrollView>
```

| Prop | Type | Description |
|---|---|---|
| `scrollDirection` | `string` | `"vertical"` (default) or `"horizontal"` |
| `physics` | `string` | `"bouncing"`, `"clamping"`, `"always"`, `"never"`, `"page"` |
| `reverse` | `boolean` | Reverse scroll direction |
| `padding` | `EdgeInsetsGeometry` | Inner padding |
| `controller` | `ScrollController` | Programmatic scroll control (see [Handles](/docs/building/handles)) |
| `clipBehavior` | `string` | Clip behavior |
| `keyboardDismissBehavior` | `string` | `"manual"` or `"onDrag"` |

## Layout

Every element that accepts children supports `layout`, because JSX can't enforce "exactly one child" vs "many children" at the type level. Several children are a column unless `layout` says otherwise, so instead of separate `Row` and `Column` components, Fuse uses `layout` as a universal layout config. That includes generated widgets with a single `child` (`Card`, `Padding`, `DecoratedBox`...). A `<Modal>` among the children takes no part in the layout.

```tsx
{/* Horizontal row with spacing */}
<View layout={{ direction: "horizontal", gap: 12 }}>
  <Text>Left</Text>
  <Text>Right</Text>
</View>

{/* Centered content filling available space */}
<View layout={{ align: "center", justify: "center", expand: true }}>
  <Text>Centered</Text>
</View>

{/* Space between items */}
<View layout={{ justify: "spaceBetween" }}>
  <Text>Start</Text>
  <Text>End</Text>
</View>
```

### LayoutInput

| Property | Type | Default | Description |
|---|---|---|---|
| `direction` | `string` | `"vertical"` | `"horizontal"` or `"vertical"` |
| `gap` | `number` | `0` | Spacing between children (pixels) |
| `align` | `string` | `"start"` | Cross-axis: `"start"`, `"center"`, `"end"`, `"stretch"` |
| `justify` | `string` | `"start"` | Main-axis: `"start"`, `"center"`, `"end"`, `"spaceBetween"`, `"spaceAround"`, `"spaceEvenly"` |
| `expand` | `boolean` | `false` | Fill available space on main axis |

### Filling the width

Layout follows Flutter: a child of a column takes its own width, not the column's. To make one child fill the cross axis, give it `width={Infinity}` (Flutter's `double.infinity`). To make every child fill it, use `align: "stretch"`; as in Flutter, that overrides the children's own widths.

```tsx
<View layout={{ gap: 12 }}>
  <View width={64} height={64} decoration={{ shape: "circle", color: "#F97316" }} />
  <View width={Infinity} height={48} decoration={{ color: "#F97316", borderRadius: 12 }} />
  <View width={Infinity}>
    <Text textAlign="center">Centered in the full width</Text>
  </View>
</View>
```

### flex

`flex` on a child gives it a share of the free space along the layout's main axis, as CSS `flex: 1` and Flutter's `Expanded(flex: 1)` do. Every element takes it, generated widgets too (`<Card flex={1}>`); it means something only inside a layout (an element with several children, a `Row`, a `Column`).

```tsx
<View layout={{ direction: "horizontal", expand: true }}>
  <View flex={1} decoration={{ color: "#EF4444" }}>
    <Text>Takes remaining space</Text>
  </View>
  <View width={100} decoration={{ color: "#2563EB" }}>
    <Text>Fixed 100px</Text>
  </View>
</View>
```

## Gestures

For something the user presses, use [`Pressable`](/docs/building/core-widgets#pressable): tap, long press, keyboard activation, and a button to screen readers.

```tsx
import { Pressable, Text, View } from "solid-fuse";

<Pressable onPress={() => setCount((c) => c + 1)}>
  <View padding={16} decoration={{ color: "#3B82F6", borderRadius: 8 }}>
    <Text color="#FFFFFF">Tap me</Text>
  </View>
</Pressable>
```

For drags, scales, double taps and the rest, use Flutter's `GestureDetector` from the generated layer. Its props and event details are Flutter's:

```tsx
import { GestureDetector } from "#fuse/flutter";

<GestureDetector onPanUpdate={(d) => setX((x) => x + d.delta.dx)}>
  <View width={80} height={80} decoration={{ color: "#10B981" }} />
</GestureDetector>
```

## Values

Colors, insets, decorations and text styles are Flutter's own types: `Color`, `EdgeInsetsGeometry`, `BoxDecoration`, `TextStyle`, from your app's generated `#fuse/flutter`. Core widgets and generated widgets take the same ones, so a value built for one fits the other. Each type also takes short forms:

| Type | Short forms |
|---|---|
| `Color` | `"#rgb"`, `"#rgba"`, `"#rrggbb"`, `"#rrggbbaa"` (alpha last, as in CSS); `{ r, g, b, a? }` (0–255, alpha 0–1) |
| `EdgeInsets` | `16` (all sides); `{ horizontal, vertical, top, right, bottom, left }` (a side wins over its axis, the rest is 0) |
| `BorderRadius` | `12` (all corners); `{ topLeft, topRight, bottomLeft, bottomRight }` |
| `Border` | `{ width?, color? }` (the same side all around) |
| `Gradient` | `{ colors, stops?, begin?, end? }` (linear, left to right by default) |
| `Alignment` | `"topLeft"`, `"center"`, `"bottomRight"`... |
| `FontWeight` | `100`–`900` |
| `Offset` | `[dx, dy]` |
| `TextDecoration` | `"underline"`, `"overline"`, `"lineThrough"`, `"none"` |
| `Duration` | milliseconds: `300` |

A plain object is the short form when the type has one, else the type's own constructor: `decoration={{ color, borderRadius }}` is `BoxDecoration(color:, borderRadius:)`. Anything else, call the builder:

```tsx
import { Border, BorderSide } from "#fuse/flutter";

<View
  padding={{ horizontal: 16, vertical: 8 }}
  decoration={{
    color: "#FFFFFF",
    borderRadius: 12,
    border: Border({ bottom: BorderSide({ width: 1, color: "#E0E0E0" }) }),
    boxShadow: [{ blurRadius: 8, offset: [0, 2], color: "#0001" }],
    gradient: { colors: ["#2563EB", "#9333EA"], begin: "topLeft", end: "bottomRight" },
  }}
/>
```

See [Generating bindings](/docs/extending/generating) for where short forms come from.

### TransformInput

```tsx
<View transform={{ rotate: 0.1 }} />           {/* radians */}
<View transform={{ scale: 1.5 }} />
<View transform={{ translateX: 10, translateY: -5 }} />
```
