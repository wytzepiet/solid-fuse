When something is better written in Dart (a custom painter, a widget that follows a finger, a wrapper around a plugin), write it as ordinary Flutter. It crosses to JSX the same way Flutter's own widgets do.

## A widget

Export it from `dart/lib/fuse.dart` (`export 'src/badge.dart';`), or declare it right in that file.

```dart title="dart/lib/src/badge.dart"
import 'package:flutter/widgets.dart';

class Badge extends StatelessWidget {
  const Badge({super.key, required this.label, this.count = 0});
  final String label;
  final int count;
  @override
  Widget build(BuildContext context) => Text('$label ($count)');
}
```

```tsx
import { Badge } from "#fuse/my_app";

<Badge label="Inbox" count={3} />;
```

The module is named after your Dart package (`name:` in `dart/pubspec.yaml`). Props are the constructor's parameters; `child` and `children` are JSX children. The rules are those of [All of Flutter from JSX](/docs/flutter/widgets#from-dart-to-jsx).

## A class with state or methods

A class with mutable state, a `dispose()`, or one that is a `Listenable` becomes a [controller](/docs/flutter/controllers): `createX()` in JS, with its getters as signals and its methods as functions.

```dart title="dart/lib/src/counter.dart"
import 'package:flutter/foundation.dart';

class Counter extends ChangeNotifier {
  int _value = 0;
  int get value => _value;
  void add(int by) { _value += by; notifyListeners(); }
}
```

```tsx
import { createCounter } from "#fuse/my_app";

const counter = createCounter();
<Text>{counter.value()}</Text>
<Pressable onPress={() => counter.add(1)}><Text>Add</Text></Pressable>
```

This is the usual way to reach a plugin: a small Dart class that calls it, with the methods your app needs.

## Shorthands

Some values have a short form:

| Short form | Means |
|---|---|
| `padding={8}` | `EdgeInsets.all(8)` |
| `padding={{ horizontal: 16, top: 8 }}` | `EdgeInsets.fromLTRB(16, 8, 16, 0)` |
| `borderRadius={12}` | `BorderRadius.circular(12)` |
| `color="#ff8800"` | the CSS hex color (`#rgb`, `#rgba`, `#rrggbb`, `#rrggbbaa`) |
| `color={{ r: 255, g: 136, b: 0, a: 0.5 }}` | `Color.fromRGBO(255, 136, 0, 0.5)` |
| `fontWeight={600}` | `FontWeight.w600` |
| `alignment="topLeft"` | `Alignment.topLeft` |
| `offset={[0, 2]}` | `Offset(0, 2)` |
| `duration={300}` | 300 milliseconds |

The full list is in [Shorthands](/docs/reference/shorthands). A short form works wherever a prop takes that type, or a supertype of it (`padding` takes `EdgeInsetsGeometry`), on core widgets and generated ones alike.

You can add your own with `@fuseShorthand`. Write a Dart function that returns the type and takes a `bool`, a number, a `String`, a `List`, or only named parameters (an object):

```dart
@fuseShorthand
Offset offsetSquare(double v) => Offset(v, v);

@fuseShorthand
Point pointAt({double x = 0, double y = 0}) => Point(x, y);
```

A type has at most one shorthand per kind of input. `@FuseShorthand(ts: ...)` narrows the TypeScript type: solid-fuse's color shorthand gives `` r'`#${string}`' ``.

A plain object (no `$`) goes to the type's object shorthand if it has one, else to its unnamed constructor. With an object shorthand, the unnamed constructor is still there as the builder (`Point(1, 2)`).

Only a type's owner gives it short forms: solid-fuse for Flutter's and Dart's types, a package for its own. `fuse gen` refuses the rest and says why in `fuse/gen-report.txt`. That keeps one meaning for `padding={{...}}` in every app.

## Implementing a Dart class in JS

Where Dart takes an abstract class (a formatter, a delegate), you can implement it in JS: pass an object literal with a function for each abstract member. Its Dart subclasses still work as values, with their builders:

```tsx
<TextField
  inputFormatters={[
    LengthLimitingTextInputFormatter(20),
    { formatEditUpdate: (oldValue, newValue) => ({ ...newValue, text: newValue.text.toUpperCase() }) },
  ]}
/>
```

Dart calls each function when it needs the member. One that returns a value is called synchronously, like a builder, so it must return at once. A getter is a function without arguments. The object must be a plain object whose functions don't use `this`: a class instance's methods aren't found.
