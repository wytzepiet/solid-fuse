The components `solid-fuse` exports, with their props. Guides: [Layout](/docs/build/layout), [Text and input](/docs/build/text-and-input), [Pressing and gestures](/docs/build/pressing-and-gestures), [Overlays](/docs/build/overlays). Value types (`Color`, `EdgeInsetsGeometry`...) and their short forms: [Shorthands](/docs/reference/shorthands).

Every element, generated ones too, also takes:

| Prop | Type | Description |
|---|---|---|
| `flex` | `number` | Share of the parent layout's free space |
| `layout` | `LayoutInput` | How its children lay out, when it has children |
| `testId` | `string` | Finds the element in tests and tools ([Drive the app](/docs/agents/drive#find-elements)) |

## LayoutInput

| Property | Type | Default | Description |
|---|---|---|---|
| `direction` | `"vertical" \| "horizontal"` | `"vertical"` | |
| `gap` | `number` | `0` | Space between children |
| `align` | `"start" \| "center" \| "end" \| "stretch"` | `"start"` | Cross axis |
| `justify` | `"start" \| "center" \| "end" \| "spaceBetween" \| "spaceAround" \| "spaceEvenly"` | `"start"` | Main axis |
| `expand` | `boolean` | `false` | Fill the main axis |

## View

| Prop | Type | Description |
|---|---|---|
| `layout` | `LayoutInput` | How the children lay out (see [Layout](#layout) below) |
| `padding` | `EdgeInsetsGeometry` | Inner spacing |
| `margin` | `EdgeInsetsGeometry` | Outer spacing |
| `width` / `height` | `number` | Fixed dimensions |
| `minWidth` / `maxWidth` | `number` | Size constraints |
| `minHeight` / `maxHeight` | `number` | Size constraints |
| `aspectRatio` | `number` | Width-to-height ratio |
| `alignment` | `AlignmentGeometry` | Align child within view |
| `decoration` | `BoxDecoration` | Background, borders, shadows, gradients |
| `foregroundDecoration` | `BoxDecoration` | Decoration painted on top |
| `opacity` | `number` | 0–1 transparency |
| `transform` | `TransformInput` | Rotate, scale, translate |
| `clipBehavior` | `string` | Clip behavior (`"hardEdge"`, `"antiAlias"`, `"none"`) |
| `flex` | `number` | Share of the parent layout's free space (see [flex](#flex)) |
| `testId` | `string` | Finds the element in tests and tools; on every element (see [Developing with agents](/docs/agents/drive#find-elements)) |
| `visible` | `boolean` | Show/hide without removing from tree |
| `ignorePointer` | `boolean` | Disable hit testing |

`transform` takes `{ rotate }` (radians), `{ scale }`, `{ translateX, translateY }`.

## RadioGroup

Groups the radios inside it, as Flutter's `RadioGroup` does: the radio whose `value` equals the group's is selected. The radios come from a design package.

```tsx
import { Radio } from "@solid-fuse/material";

<RadioGroup value={plan()} onChange={setPlan}>
  <Radio value="free" /> <Radio value="pro" />
</RadioGroup>
```


## Expandable

A header that shows or hides its body (the children), animated.

```tsx
<Expandable header={<Text>Details</Text>}>
  <Text>The body.</Text>
</Expandable>
```

Props: `header`, `expanded` / `defaultExpanded` / `onExpandedChange`, `disabled`, `duration` (default 200), `maintainState` (default true).
