A new app's Dart is one file. You rarely change it.

```dart title="dart/lib/main.dart"
import 'package:flutter/widgets.dart';
import 'package:solid_fuse/solid_fuse.dart';

import '_generated/fuse_packages.dart';

void main() async {
  FuseBinding.ensureInitialized();

  final runtime = await FuseRuntime.create();
  registerFusePackages(runtime);
  await runtime.start();

  runApp(FuseView(runtime: runtime));
}
```

| Line | Does |
|---|---|
| `FuseBinding.ensureInitialized()` | Flutter's binding. In debug and profile builds it adds [Marionette](https://pub.dev/packages/marionette_flutter), so [`fuse drive`](/docs/agents/drive) can tap, type and take screenshots. Release builds get the plain binding |
| `FuseRuntime.create()` | Makes the runtime. The JavaScript engine isn't running yet |
| `registerFusePackages(runtime)` | Generated by `fuse link`. Registers every Fuse package and the generated adapters |
| `runtime.start()` | Starts the JavaScript engine. In debug it connects to `fuse dev`; in release it loads the bundle from the app's assets. Everything must be registered before this |
| `FuseView(runtime: runtime)` | Draws what JS renders. The app root (`<MaterialApp>`...) is in JS, so Dart runs `FuseView` on its own |

## FuseRuntime

| Member | |
|---|---|
| `registerWidget(type, builder)` | A hand-written widget ([Widgets by hand](/docs/flutter/by-hand/widgets)) |
| `registerHandle(type, factory)` | A hand-written handle or page type ([Handles](/docs/flutter/by-hand/handles), [Pages](/docs/flutter/by-hand/pages)) |
| `registerRoute(type, (context, node, content) => Route)` | A modal route type for `<Modal type>` |
| `channels` | `send`, `call`, `on`: messages to and from JS ([Channels](/docs/flutter/channels)) |
| `start()` | Start the engine |

Register your own between `registerFusePackages(runtime)` and `runtime.start()`.

## FuseView

A widget. Besides a whole app, it can be one screen or one part of a Flutter app written in Dart.

## FuseNode

What a hand-written widget reads its props from: `node.string('label')`, `node.value<Color>('color')`, `node.callback('onTap')`, `node.layoutChildren`. The accessors are listed in [Widgets by hand](/docs/flutter/by-hand/widgets#fusenode-prop-accessors).

## Annotations

`@fuseShorthand` and `@FuseShorthand(ts: ...)` mark a Dart function as a short form of its return type ([Shorthands](/docs/flutter/your-own-dart#shorthands)). They do nothing at run time.
