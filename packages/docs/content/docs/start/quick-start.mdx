## What you need

- [Node.js](https://nodejs.org/) 20.19 or newer, with npm, pnpm, yarn or bun
- [Flutter](https://flutter.dev/docs/get-started/install) 3.50 or newer
- [Rust](https://rustup.rs/), for now: the first build compiles the JavaScript engine (a few minutes, once)

## Create an app

```bash
npm create solid-fuse@latest my-app
cd my-app
npm run dev
```

`create` asks for a design (`material`, `cupertino`, `adaptive` or `none`) and the platforms, writes the app, installs it and runs `git init`. `-y` takes the defaults.

`npm run dev` starts the app on a simulator, a device or your desktop. pnpm, yarn and bun work the same way. Not sure your machine is ready? `npx fuse doctor` checks it.

## Change something

Open `src/app/index.tsx` and change the text. The running app updates when you save, and keeps its state.

```tsx title="src/app/index.tsx"
import { createSignal } from "solid-js";
import { AppBar, Button, Scaffold } from "@solid-fuse/material";
import { Text, View } from "solid-fuse";

export default function Home() {
  const [count, setCount] = createSignal(0);
  return (
    <Scaffold appBar={<AppBar title="My app" />}>
      <View width={Infinity} height={Infinity} layout={{ align: "center", justify: "center", gap: 16 }}>
        <Text fontSize={48}>{count()}</Text>
        <Button onPress={() => setCount(count() + 1)}>Add one</Button>
      </View>
    </Scaffold>
  );
}
```

## What's in the folder

```
my-app/
  src/
    index.tsx        starts the app
    app.tsx          the app root: picks the design, draws the pages
    app/
      index.tsx      the first page
  dart/              the Flutter project; you rarely open it
  fuse/              generated, don't edit
  fuse.config.ts
  AGENTS.md          tells a coding agent how to work here
```

Each file in `src/app/` is a page: add `src/app/settings.tsx` and `nav.push("/settings")` opens it. Every file is listed in [Project files](/docs/reference/project-files).

## On a machine with no screen

A cloud agent or CI runs the same app on Linux:

```bash
npx fuse dev --headless
npx fuse drive take-screenshots -o screen.png
```

See [Agents](/docs/agents).
