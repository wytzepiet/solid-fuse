title: Input types
description: Shared shapes for colors, spacing, borders, decorations, and transforms

These types are used across multiple widgets for colors, spacing, borders, and more. They're documented once here and referenced from each widget that accepts them. They map onto Flutter's [`Color`](https://api.flutter.dev/flutter/dart-ui/Color-class.html), [`EdgeInsets`](https://api.flutter.dev/flutter/painting/EdgeInsets-class.html), [`BorderRadius`](https://api.flutter.dev/flutter/painting/BorderRadius-class.html), and [`BoxDecoration`](https://api.flutter.dev/flutter/painting/BoxDecoration-class.html).

## Color

Colors are `Color` values — build them with a constructor or a named constant, imported from `solid-fuse`:

```tsx
import { Color } from "solid-fuse";

// Named constants
<Text color={Color.red} />
<Text color={Color.transparent} />

// rgb (r/g/b: 0–255, a: 0–1) · hsl (h: 0–360, s/l: 0–100) · oklch (l: 0–1, c, h°)
<View decoration={{ color: Color.rgb(255, 0, 0) }} />
<View decoration={{ color: Color.rgb(255, 0, 0, 0.5) }} />
<View decoration={{ color: Color.hsl(0, 100, 50) }} />
<View decoration={{ color: Color.oklch(0.7, 0.15, 30) }} />

// hex (3, 4, 6, or 8 chars) — CSS semantics, alpha LAST (#RGBA / #RRGGBBAA)
<View decoration={{ color: Color.hex("#F00") }} />
<View decoration={{ color: Color.hex("#FF000080") }} />  {/* red at 50% alpha */}
```

`Color` is immutable; its operations return new colors and chain left-to-right (like a pipe). `mix` and the lightness/chroma/hue ops work in OKLab/OKLCH, so blends stay perceptually smooth instead of muddying through grey:

```tsx
Color.red.withAlpha(0.5)           // translucent red
Color.blue.lighten(0.1)            // L +0.1 in OKLCH
Color.blue.darken(0.1)
Color.red.saturate(0.05)
Color.red.rotateHue(30)            // hue +30°
Color.red.mix(Color.blue, 0.5)     // perceptual midpoint (OKLab)

Color.teal.darken(0.1).withAlpha(0.8)   // chains
```

Named constants: `transparent`, `white`, `black`, `red`, `blue`, `green`, `grey`, `orange`, `purple`, `yellow`, `teal`, `cyan`, `amber`, `indigo`, `pink`, `brown` (the Material 500 swatch).

## EdgeInsetsInput

Padding and margin accept a number (all sides) or an object:

```tsx
<View padding={16} />                                    {/* all sides */}
<View padding={{ horizontal: 16, vertical: 8 }} />       {/* symmetric */}
<View padding={{ top: 10, left: 20, bottom: 10 }} />     {/* individual */}
```

## BorderRadiusInput

```tsx
<View decoration={{ borderRadius: 12 }} />                          {/* all corners */}
<View decoration={{ borderRadius: { topLeft: 12, topRight: 12 } }} /> {/* individual */}
```

## DecorationInput

Combines background, borders, shadows, gradients, and images:

```tsx
<View decoration={{
  color: Color.white,
  borderRadius: 12,
  border: { width: 1, color: Color.hex("#E0E0E0") },
  shadow: [{ blurRadius: 8, spreadRadius: 1, color: Color.hex("#0001"), offsetY: 2 }],
  gradient: {
    type: "linear",
    colors: [Color.blue, Color.purple],
    begin: "topLeft",
    end: "bottomRight",
  },
}} />
```

## TransformInput

```tsx
<View transform={{ rotate: 0.1 }} />           {/* radians */}
<View transform={{ scale: 1.5 }} />
<View transform={{ translateX: 10, translateY: -5 }} />
```
